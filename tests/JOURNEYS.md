# Acceptance Journeys

## Author to exact-SHA evidence

1. Instantiate the template and replace all identity placeholders.
2. Add captured offline contract fixtures and model tests.
3. Run coverage, repeated concurrency, mutation, audit, gates, and shell lint.
4. Commit a clean source tree.
5. Run the Buzz journey and inspect the populated preview.
6. Confirm both receipts name the clean commit and matching package hashes.
7. Submit that exact SHA with CI and Buzz evidence links.

## User install to primary action

1. Install the plugin on stock Omarchy.
2. Confirm the pill renders useful bounded state.
3. Open the panel by pointer and keyboard.
4. Exercise the plugin's primary action against deterministic fixture data.
5. Confirm the fixed-argv action or external handoff matches the expected value.
6. Confirm errors remain visible and do not silently erase last-good state.
